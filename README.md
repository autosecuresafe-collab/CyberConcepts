# CyberConcepts — Cybersecurity Learning Hub

Interactive cybersecurity lessons with diagrams, worked examples, failure scenarios, and quizzes — leaning toward automotive cybersecurity (ECUs, CAN bus, secure boot, OTA updates, V2X, ADAS, and in-vehicle app platforms).

## What's here

- `index.html` — the full hub as one self-contained page: 53 modules, from Cryptography Fundamentals through Android Automotive Security, with hands-on exercises and simulation labs across modules.
- New lessons are added regularly; this snapshot is current as of November 3, 2026.

## Reading it

Open `index.html` in any browser — no build step, no server needed. To serve it as a site, enable GitHub Pages on this repo (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
